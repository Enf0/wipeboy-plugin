# Wipeboy for Claude

The Wipeboy connector at https://wipeboy.enfo.dev/mcp and its raid-log-analysis skill, as a Claude plugin for The Dragonfell Tribe (Kazzak-EU). With the skill,
Claude reads raid logs the way the method says; a connector alone brings only the tools.

## Add it

In Claude (claude.ai or Claude Desktop): **Customize → Plugins → Add → Add marketplace**, enter `Enf0/wipeboy-plugin`, then add
the Wipeboy plugin and sign in with Warcraft Logs. Claude keeps it up to date.

In Claude Code: `/plugin marketplace add Enf0/wipeboy-plugin`, then `/plugin install wipeboy@wipeboy`.

Made with [Wipebot](https://github.com/Enf0/wipebot): `wipebot plugin DIR` writes this repository.
